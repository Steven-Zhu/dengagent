# DengAgent Wiki

DengAgent 帮你把在 Codex 中设计好的方案交给自选模型执行，在能力与成本之间取得合适的平衡。这里说明如何接入、交办、观察和验收。

**目前支持 Codex 接入；其他 Agent 的接入正在开发中。**

Currently supports Codex integration. Integrations with other agents are in development.

## 从 npm 安装 / Install from npm

> npm 发布正在自动校验中。完整安装包上线后再使用下方注册表安装命令；临时占位包不包含 CLI。

```sh
npm install --global dengagent
deng init
```
