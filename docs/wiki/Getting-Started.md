# 开始使用

[Wiki 首页](Home.md) · [接入状态](Integrations.md)

当前使用入口是 Codex，其他 Agent 接入正在开发中。

## 安装与配置

准备 Node.js 24+、npm 10+，从 npm 安装并初始化：

> npm 发布正在自动校验中。完整安装包上线后再使用下方注册表安装命令；临时占位包不包含 CLI。

```sh
npm install --global dengagent
deng init
```

安装与升级详情见[安装指南](../npm-installation.md)。配置自己的模型 API 地址、模型与 Key，重载 Codex 的 MCP 连接。

升级时运行 `npm install --global dengagent@latest`，再执行 `deng init` 刷新接入；不要为了升级中断已有任务。

## 先设计，再交接

先与 Codex 讨论目标、允许修改的文件、输出形式和固定验收检查。方案明确后，告诉 Codex：

> 按刚才设计的方案，使用 Deng 执行。先确定文件和命令授权范围以及固定验收检查，再提交任务；完成后检查产物与交付清单。

Codex 准备方案文档和任务范围，Deng 使用所配置的模型执行。首次建议选择[第一次任务](../first-task.md) 中的小改动。

## 观察与检查

控制台显示公开输出、工具执行和结果；Codex 可查询简洁的任务状态与交付信息。检查完成后的实际文件、测试结果与交付版本。不同任务、模型和供应商的能力与开销不同，可以按实际结果调整选择。

如果遇到接口 401/403，先检查供应商凭证与访问权限，按[故障指南](../troubleshooting.md) 排查；涉及未确认用量或命令结果时，按[恢复说明](../recovery.md) 处理，不通过反复提交制造新任务。
